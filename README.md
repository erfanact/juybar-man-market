# آنلاین مارکت جویبار من

فروشگاه فارسی و راست‌چین با Next.js 15 و React 19.

## امکانات پیاده‌سازی‌شده در این نسخه
- صفحه اصلی واکنش‌گرا با تم مشکی و طلایی
- فهرست محصولات نمونه در دسته‌های میوه و سبزی، لبنیات و مواد غذایی
- فیلتر دسته‌بندی محصولات
- افزودن محصول به سبد، کم‌وزیاد کردن تعداد و محاسبه جمع و هزینه ارسال
- نمایش هزینه ارسال نمونه ۲۹٬۰۰۰ تومان و پرداخت در محل

## اجرای محلی
1. Node.js نسخه 20 یا جدیدتر نصب کنید.
2. در پوشه پروژه اجرا کنید:
   ```bash
   npm install
   cp .env.example .env.local
   npm run dev
   ```
3. نشانی `http://localhost:3000` را باز کنید.

## مهم: پیش از دریافت سفارش واقعی
این نسخه یک نمونه تعاملی فرانت‌اند است؛ هنوز سفارش‌ها را ذخیره یا پیامک نمی‌کند و درگاه پرداخت ندارد. نام و قیمت محصولات نمونه‌اند و باید با اطلاعات واقعی فروشگاه جایگزین شوند. برای فروش واقعی باید:
- پروژه Supabase ساخته و متغیرهای محیطی تنظیم شوند.
- جداول، سیاست‌های دسترسی RLS و ثبت سفارش سمت سرور تکمیل و آزمایش شوند.
- پنل مدیریت محصولات، قیمت و موجودی ساخته شود.
- آدرس و تلفن فروشگاه، محدوده ارسال و هزینه پیک تأیید شوند.
- در صورت نیاز، درگاه پرداخت و سرویس پیامک متصل شوند.
- سیاست حریم خصوصی و شرایط مرجوعی/ارسال درج شوند.

## انتشار روی اینترنت
می‌توانید این پوشه را به GitHub منتقل و در Vercel به‌عنوان پروژه Next.js وارد کنید. پس از تنظیم متغیرهای محیطی و تکمیل قابلیت‌های سفارش واقعی، دامنه را متصل کنید. انتشار عمومی این بسته به‌تنهایی به معنی آماده بودن برای دریافت سفارش واقعی نیست.

## امنیت
- کلید service role سوپابیس را هرگز در کد مرورگر یا متغیر `NEXT_PUBLIC_` قرار ندهید.
- قیمت و مبلغ سفارش باید فقط در سرور از پایگاه داده محاسبه شوند.
- OTP باید تاریخ انقضا، محدودیت ارسال/تلاش و محافظت در برابر سوءاستفاده داشته باشد.
